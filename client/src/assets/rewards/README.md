# Reward card photography

These project-owned photographs were created with the built-in image generation tool
and exported as 1200px-wide WebP files at quality 80 for the existing reward cards.
No external image service or API key is required at runtime.

| Asset | Intended reward |
| --- | --- |
| `fitness-accessory.webp` | Fitness accessories |
| `movie-ticket.webp` | Cinema / movie tickets |
| `health-check.webp` | Health checks and medical vouchers |

An administrator's configured image URL takes priority. A matching bundled photo
is used if that URL is empty or fails. Unrecognized rewards retain the gift icon.
Card layout, pricing, stock and redemption behavior are unchanged.

## Generation prompts

### Fitness accessory

Use case: product-mockup. Create a landscape photorealistic editorial product photograph for the existing Fitness Accessory reward card in a blood-donation website. A pair of matte charcoal dumbbells, a neatly rolled muted coral yoga mat, a stainless steel water bottle, and a small white towel on a warm light stone surface in a bright modern home workout space. Natural morning window light, tactile materials, clean premium catalog photography. Wide landscape composition, keep the equipment grouped centrally with breathing room so the central horizontal band can be cropped for a shallow card image. No people, no words, no numbers, no logos, no watermark. Output an actual photograph, not a website mockup.

### Movie ticket

Use case: photorealistic-natural. Create a landscape photorealistic photograph for the existing Movie Ticket reward card in a blood-donation website. A classic red and white striped popcorn carton filled with popcorn and two plain unprinted paper cinema admission stubs, resting on a plush burgundy-red cinema seat armrest; softly blurred empty movie theater seats behind. Warm cinematic practical lighting with soft amber bokeh, inviting realistic material detail, premium editorial photography. Wide landscape composition, popcorn and tickets centered with ample breathing room for a shallow horizontal crop. No readable text, no people, no logos, no watermark. An actual scene photograph, not a website mockup.

### Health check

Use case: photorealistic-natural. Create a landscape photorealistic editorial photograph for the existing Health Check Voucher reward card in a blood-donation website. A dark charcoal stethoscope, a manual blood pressure cuff with a round pressure gauge, and a closed blank white medical folder arranged neatly on a pale blue-white clinic desk, softly blurred bright clinic interior in the background. Calm natural daylight, subtle blue and coral accents, professional and reassuring premium healthcare photography. Wide landscape framing, keep the equipment centrally placed with breathing room so it survives a shallow horizontal card crop. No people, no needles, no blood, no readable text, no logos, no watermark. Photograph only, not a website mockup.
